# 0.5.0 验证范围（2026-11-14）

设备：小米 L43M7-EA，Android 5.1.1/API22、ARMv7、1GB 内存。

- 核心测试201项：199通过、2项上游跳过；构建和 lint 通过。新增原始加密块缓存、随机读取、并发去重、取消、磁盘上限、清理、后台让行及同画质备用地址选择测试。
- 实际复现下载不足：约2.45MB的一集耗时约54.5秒，均速约44KiB/s；按该集时长及2倍速需要约70KiB/s。实际解码器为Amlogic HEVC硬解，日志出现约9秒缓冲，不能归咎于宽带购买速率或认定为解码问题。
- 同一局域网电脑对同文件同一512KiB段测试，主地址约4.98秒，备用约0.34秒，内容摘要一致；这是该时间和分段的抽样，不代表永久速度。
- 初版缓存实现运行后，在网络恢复足够速率时，滚动完成后续2至3集；连续8次自动切集保持同一播放器，缓冲累计未增长。按转场日志间隔与媒体时长/2比较，整体额外约0.1秒；这不是视频首帧或黑屏时长测量，不保证所有片源无缝。
- 最终安装包使用256KiB选源探测，实际选中备用地址：后续集1MiB预热约0.9至1.3秒（所选线路请求累计耗时），在片尾前入队，自动转场仍复用同一播放器。实际视频画面无法靠远程截图可靠确认，未将日志等同于现场画面验证。
- 缓存采用磁盘原始加密数据块，已完成集移出队列后删除，观察使用量约7至13MiB，应用PSS抽样约78MiB。未做长时间压力测试。
- 解码模式只对电视已有系统解码器排序，不额外内置软件解码。当前HEVC没有可用系统软解时，界面拒绝该手动选择并保留原模式。

未修改电视或路由器DNS、网关或代理。持续下载不足、接口不可用和编码变化仍可能引起等待。
