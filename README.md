# 青聚 0.5.0

面向老电视适配的短剧、漫剧客户端，让 Android 5.0 及以上的旧电视通过遥控器浏览、搜索和播放内容，支持倍速、清晰度选择、观看记录、同系列季度切换与连续播放。

重点适配小米 L43M7-EA：Android 5.1.1 / API22、32位 ARMv7、1GB内存，已在该设备实测；其他电视的兼容性仍需验证。当前为侧载测试版，GPL-3.0-only 开源。源码仓库：[dsantial/qingju-tv](https://github.com/dsantial/qingju-tv)。

## 0.5.0 缓冲与解码选择

- 播放页「更多 → 解码方式」提供自动、优先硬解、优先系统软解。默认推荐自动；实际可用项由电视和视频格式决定，没有额外内置 FFmpeg 软解。旧电视的 H.265 通常只能硬解，不能通过切软解解决下载慢。
- 「更多 → 后续整集预缓存」可选关闭或后续1/2/3集，默认3集。关闭整集预缓存仍保留下一集轻量预读。优先供应当前播放，网络余量足够才下载后续内容。
- 当前集及后续缓存使用磁盘上的原始加密数据块，最多192MiB、单集最多64MiB，剩余空间不足64MiB时停止新增缓存；看完移出队列后删除，退出播放清理，不下载整季。
- 同一播放器提前排入下一集，保留可复用的解码器；内存缓冲目标15至60秒媒体时间，受16MiB目标约束。2倍速时60秒媒体时间约供观看30秒。
- 保留同一画质的备用视频地址，首次读取时以有界小段探测选择较快地址；主地址可用时比较同段内容与总长，选定后本集固定来源，避免缓存块混源。不修改系统DNS或代理。
- 「更多 → 播放与缓存状态」展示实际解码器、下载均速、缓冲、缓存和卡顿统计。下载均速只代表当前视频请求，不等于宽带测速。

缓存解决网络波动，预读与播放器队列减少切集等待，两者配合使用。持续下载速度低于当前画质及倍速所需时，仍会缓冲；不同分辨率/编码也可能需要重建解码器，不能保证零间隔。

## 0.4.2 编码兼容与季度切换

- 修复部分剧集全部返回 ByteVC2 时无法播放：先读取备用模型，必要时额外请求一次兼容编码，继续按实际返回编码筛选，不强行播放旧电视不支持的 ByteVC2。
- 三条线路均返回空响应时，可受限刷新匿名播放会话并再试一轮；有5分钟冷却，明确的业务/HTTP拒绝和传输失败不会触发刷新。保留账号、本地历史与收藏。
- 详情页下方展示同系列可用季度，按季号排序；播放控制栏新增「季度」，可直接切到其他季，按各季独立历史续播，不用退出重新搜索。季度查询在独立后台任务运行，不打断当前视频；不自动跨季连播。

## 0.4.1 播放协议修复

更新单集取流的 Gorgon/Argus/Ladon 签名，替换失效的旧播放签名；兼容新的数组视频模型、加密信息和清晰度字段。保留已有界面、遥控操作、倍速及下一集限量预取。匿名播放请求不携带账号 Cookie，重试限制在三条线路，服务端明确拒绝时停止重试。来源和许可见[NOTICE](NOTICE.md)。

## 播放修复

- 保留HGTV剧架、排行榜、分类、收藏与历史界面。
- 统一遥控确认和媒体暂停键；菜单先聚焦暂停按钮，暂停时保持控制栏可见；处理按下/抬起和长按重复事件。
- 清晰度上限提供480P/720P/1080P，以接口实际可用资源为准；切画质保留播放位置和暂停意图。
- 使用API22兼容TextureView。画面提供原比例、铺满裁剪、拉伸，以及125%/150%放大裁剪并保存选择；16:9片源在16:9屏幕上前三项可能相同，视频内嵌黑边也会影响效果。
- 同一ExoPlayer保留当前集和后续队列；后台单线程依序填充缓存并提前排入下一集，跨集不重建播放页，兼容时复用解码器。旧集移出队列后释放；失败10秒后有限重试一次。
- 连续播放仍取决于网络、接口响应及片源编码/分辨率变化，不保证每次切集零间隔；没有下载整剧或合并大文件。

竖屏或横屏由片源决定，例如本次实测的《大唐憨婿》是竖屏源。默认保留原比例；「铺满裁剪」会裁掉部分内容，「拉伸」会改变比例，都不会生成真正的横屏片源。

## 遥控器

详情页下方可左右选择同系列季度；播放时可通过「季度」直接换季，各季按自己的观看记录续播。播放时确认键暂停/继续；菜单键打开控制栏并聚焦暂停，左右选择上一集、下一集、选集、倍速、画面和更多。控制栏隐藏时左右快退/快进10秒，上下呼出控制。画质在「更多 → 清晰度」；解码、后续整集预缓存及播放诊断均在「更多」；画面可选放大裁剪。返回进入详情。

## 构建与安装

JDK17、Android SDK Platform36 / Build Tools36.0.0、Gradle8.14.3。最低API21、target35；纯JVM应用，通过系统解码器播放，兼容本机32位ARM系统。设置ANDROID_HOME或本机local.properties。

```sh
./gradlew :core:test :app:lintDebug :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

独立包名local.qingju.tv，可覆盖更新本项目旧版本；不覆盖cn.hongguo.tv或com.hgtv.star。Debug签名用于本机测试，正式分发应使用自行保存的签名密钥。TLS保持正常证书校验。

## 已定位的 DNS 过滤兼容问题

如果片单正常而播放失败，并且注册域名 `log5-applog-lf.fqnovel.com` 被解析为 `0.0.0.0` 或 `127.0.0.1`，设备注册会被误拦截。可在确认是误拦截后，仅针对目标电视添加例外（将 `<TV_IP>` 替换为电视实际地址）：

```text
@@||log5-applog-lf.fqnovel.com^$client=<TV_IP>
```

此域同时用于平台注册/日志请求，例外应只针对目标电视的这一域，其他客户端和域名继续过滤。删除这一行即可撤销。项目未内置备用DNS、未绕过家中DNS设置。
